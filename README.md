# rea-book

逆向拆解一本书的**表达与描写**，产出一份「加载后就能按该作者风格写作」的 skill。

不是书摘，不是读后感，不是内容总结。

## 它解决什么问题

你想要的是「用这个作者的写法写我自己的文案」。

市面上大多数拆书工具给的是可数指标——平均句长、逗号密度、转折在第几句。这些数字测完，你还是写不出那个味道，因为它们描述的是**结果**，不是**写法**。

rea-book 的做法相反：它逼你贴着原文走，一段一段问「他这一招怎么使的」「他站在哪一边」，然后要求每条都能定位到原句。定位不了的，直接废掉。

## 产出分两层

| 层 | 内容 | 地位 |
|---|---|---|
| 表达与描写 | 他看见什么、站在哪、驳谁、先后顺序、用哪个动作承载情绪、结尾收还是放 | **主** |
| 可数指标 | 句长分布、标点密度、对话占比 | 辅，**只当标定靶**，写完拿来回量 |

只交第二层，等于没交；但第二层也不许缺——它是尺子。

## 六步流程

1. **定输入**——书、作者、译者。外语作品先声明「逆的是译者不是作者」。**加题材闸门**：先确认这位作者会不会写目标题材（宣言型作者写不来叙事，反之亦然）。拿错题材反复调参数，是这条线上最贵的浪费。
2. **切分**——卷 → 章 → 段，取证单元 800–2000 字。
3. **逐段取证（双问）**——每段问两件事，**缺第二问就只能产出句子层**：
   - 写法：「这一段最显眼的一招是什么？三十字以内，抄出那句原文。」
   - 表达：「这一段他主张什么？反对谁？依据哪一句？」
   - 不给封闭选项。
4. **三重验证**——能定位原文？能造出新句子？别的作者不会这么写？三问全过才留。第三问的便宜做法：拿一本同语言、同文体、不同作者的公版书同法跑一遍，比类级密度。
5. **归并**——至少两卷复现才进跨卷汇总；手法表与立场表分开出，不许混。
6. **生成作者 skill**——按模板填，每格带原文出处，附样稿。

## 第 6 步的三条硬要求（实测加上的）

- **Calibration 放第一条**：写真实作者，不是恶搞版。他大部分句子是普通的，签名招一段只出现一两次；招数堆满＝漫画，比克制的模仿离真作者更远。
- **量测值当标定靶**：先在原书上量出句长、长短句比例、标点密度、对话占比，写进 skill 当靶子，写完再量一遍比对。指标是尺子，不是交付物。
- **给「一章的形状」**：孤立的手法卡放一起只会堆砌。必须写清一章按什么顺序走（如：场面 → 长篇转述 → 一句断喝 → 展开一层 → 短收）。

## 产物长什么样

拆完一本书，你得到的不是一份报告，而是另一个 skill：`style-<作者>`。

它里面装的是写作指令：硬指标、Calibration（怎么写歪）、一章的形状、手法卡（按频次排序，每张带原文/动作/不成立条件/反例）、他怎么看、不许做什么、自检清单、示范。

示例：[`style-尼采`](https://github.com/lokn528/rea-book/blob/main/style-尼采/SKILL.md)（《查拉图斯特拉如是说》158 单元全量取证）。

## 两条硬约束

- **跨文体不比**：同一作者换文体，句长能差两倍以上。特征跟文体走，不跟人走。
- **外语作品混着译者指纹**：破折号密度、大写强调、分号、倒装，这些是译者的，不是作者的。

## 已知的坑（都踩过）

- **只问「招」会只得到句子层**。跑完一百多个单元，产出全是「怎么摆句子」，一句作者的主张都没有。必须双问。
- **给封闭选项会毁掉整个产出**。曾经用「起承转收 / 转折第几句 / 物象主辅」这套标签跑了几百个单元，聚合出来只剩指标，全废。
- **单元不能太小**。切到一条格言（约 100 字）时，判断根本出不来，十条台账只有一半成立。
- **读出答案不可复现**。同一单元跑两遍，只有 2/5 命同一条。所以只按「类」汇总，不按条算召回率。
- **硬指标会过冲**。写下限，模型就冲过头（长句全变长、逗号全堆起来）。必须同时写上界，写完回量。
- **示范会死板**。贴成品句子，模型会照抄句式。要留示范，就同时写死「同一招一篇只用一次」。
- **验证要留对照组**。至少三篇：用 skill / 只说「写成谁的风格」/ 不给风格。只比「用 vs 不用」，分不清是 skill 起效还是模型本来就会写。
- **读过的东西必须落盘**。对话上下文的压缩会吃掉细节，重读是最贵的浪费。

## 怎么用

把这个目录放进你的 skills 目录，或者直接把 `SKILL.md` 喂给 agent。然后说：

> 用 rea-book 拆《某某书》，作者某某，译者某某。
